Venta3D Pro V5 – instalación

1. Reemplaza index.html, manifest.json y sw.js en tu repositorio GitHub.
2. Mantén los iconos PNG.
3. GitHub Pages: Settings > Pages > Deploy from branch > main > /(root).
4. Abre la URL publicada.

Novedad V5:
- Cantidad a cotizar (base).
- ¿Imprimirás más? Sí/No.
- Cantidad total a imprimir.
- Al cambiar la cantidad, recalcula automáticamente filamento, purga, desperdicio, tiempo, electricidad, desgaste, adicionales, costo, margen, precio total y precio unitario.
- El precio manual corresponde al pedido completo.
- Mantiene visor/editor 3D, entregas, alertas, monedas y tiempos en horas/minutos.
